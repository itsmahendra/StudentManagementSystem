# Student Management System

A console-based Student Management System built using **Java and OOP concepts**.

## Features

* Add student
* View all students
* Search student by ID
* Update student details
* Delete student

## Technologies

* Java
* OOP
* ArrayList
* Scanner

## OOP Concepts

* Classes & Objects
* Encapsulation
* Constructors
* Getters & Setters

## Run

```bash
javac Main.java Student.java StudentManager.java
java Main
```
